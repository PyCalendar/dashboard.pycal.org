0.1.0 (unreleased)
------------------

New features
~~~~~~~~~~~~

- The dashboard of the PyCalendar community: issues for newcomers, pull requests
  to review, repositories and contributors, with a JSON API.
- The GitHub App is registered on the site at its first start; it reads the
  repositories, receives webhooks and labels pull requests.
- People sign in with GitHub only and have an account page with preferences and
  email addresses.
