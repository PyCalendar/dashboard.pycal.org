============
Report a bug
============

1. On the page of the error, open *Details to copy* and copy the text. It names
   the error, the page, the time and the version.
2. Open a `new issue
   <https://github.com/PyCalendar/dashboard.pycal.org/issues/new>`_, paste the
   details and say what you did before.

Security problems are reported privately with a `security advisory
<https://github.com/PyCalendar/dashboard.pycal.org/security/advisories/new>`_.
