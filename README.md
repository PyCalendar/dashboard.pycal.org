# dashboard.pycal.org

[![Documentation](https://img.shields.io/badge/docs-readthedocs-3b79aa)](https://dashboard-pycal-org.readthedocs.io/en/latest/)
![License: AGPL-3.0-or-later](https://img.shields.io/badge/license-AGPL--3.0--or--later-blue.svg)

A dashboard for the contributor community of [PyCalendar](https://github.com/PyCalendar):
where to start, what waits for a review, and who contributes. Its GitHub App labels
the pull requests.

Everything else is in the documentation:
[dashboard-pycal-org.readthedocs.io](https://dashboard-pycal-org.readthedocs.io/en/latest/).
